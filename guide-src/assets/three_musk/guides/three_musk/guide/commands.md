# Полезные команды

Команды вводятся в чат с `/`. Доступ к отдельным веткам зависит от прав на сервере. Если появляется сообщение о нехватке прав, сообщите администратору точную команду и текст ошибки.

## Дом и перемещение

| Команда | Для чего |
| --- | --- |
| `/sethome база` | Запомнить текущее место как дом. |
| `/home база` | Вернуться домой. |
| `/listhomes` | Показать сохранённые дома. |
| `/delhome база` | Удалить точку дома. |
| `/back` | Вернуться к предыдущей точке телепортации или смерти. |
| `/spawn` | Телепортироваться на спавн. |
| `/rtp` | Найти случайное место для исследования. |
| `/warp название` | Перейти к общему варпу. |
| `/listwarps` | Посмотреть общие варпы. |

Названия домов и варпов здесь примерные; используйте свои. Часть команд имеет задержку между применениями. В некоторых измерениях `/rtp` может быть недоступна.

## Игроки и координаты

| Команда | Для чего |
| --- | --- |
| `/tpa ник` | Запросить телепортацию к другу. |
| `/tp ник` | Телепортироваться к игроку, если сервер разрешает прямой `/tp`. |
| `/tp x y z` | Переместиться к координатам, если это разрешено вашим рангом. |
| `/gamemode survival` | Вернуться в режим выживания, если команда доступна. |
| `/gamemode spectator` | Перейти в режим наблюдателя, если команда доступна. |

Для быстрого перемещения к другу используйте прямой `/tp ник`; запрос `/tpa` пригодится, если вы хотите сначала договориться о телепортации. Селекторы `@s`, `@a`, `@e` и другие имеют отдельные ограничения сервера; они не нужны для перечисленных выше обычных команд. Не используйте `@e` без фильтра `type=...`.

## Подсказка по вводу

Нажмите Tab после названия команды: игра покажет доступные аргументы. Если команда не предлагается или не исполняется, это может быть ограничение прав, а не ошибка в синтаксисе.
