# Автообновление клиентской Craftoria через packwiz

Манифест: `https://raw.githubusercontent.com/Vadimpich/three-musk-industries-pack/main/packwiz/pack.toml`

Ссылка заработает после публикации текущих файлов репозитория в GitHub (`main`). До этого клиентам настраивать команду бессмысленно.

Это снимок нашего текущего клиентского набора: Craftoria 1.37.0 / Minecraft 1.21.1 / NeoForge 21.1.249. Он фиксирует версии 533 JAR-модов, 35 ресурспаков и 3 шейдерпаков. Текущая версия манифеста **не синхронизирует** `config/`, `options.txt`, сохранения, карты, хоткеи и другие личные данные. Серверный GuideME-ресурспак приходит при входе на сервер отдельно.

## Однократная настройка каждого клиента в Prism Launcher

1. Сделайте копию своего инстанса или хотя бы сохранений и настроек. Лучше начать с отдельной чистой копии **Craftoria 1.37.0**. Не обновляйте её через каталог сборок до другой версии.
2. Проверьте в `Редактировать инстанс → Версия`: Minecraft **1.21.1**, NeoForge **21.1.249**. Оставьте Java 21. Наш JAR не устанавливает загрузчик и не меняет Java.
3. Скачайте `packwiz-installer-bootstrap.jar` из [официального релиза packwiz-installer-bootstrap v0.0.3](https://github.com/packwiz/packwiz-installer-bootstrap/releases/tag/v0.0.3). Положите JAR в папку `minecraft` именно этого инстанса, рядом с `options.txt` (в Prism: `Редактировать инстанс → Папка → Открыть папку Minecraft`).
4. В `Редактировать инстанс → Настройки → Пользовательские команды` включите пользовательские команды и вставьте в поле **Команда перед запуском** ровно одну строку:

   ```text
   "$INST_JAVA" -jar "$INST_MC_DIR/packwiz-installer-bootstrap.jar" -s client https://raw.githubusercontent.com/Vadimpich/three-musk-industries-pack/main/packwiz/pack.toml
   ```

5. Запустите инстанс с интернетом. Первый запуск может долго скачивать файлы (~1,2 ГиБ модов плюс ресурспаки/шейдеры для чистого инстанса). При ограничениях CurseForge установщик может попросить вручную скачать отдельные моды — следуйте указанным им ссылкам. Потом он проверяет изменения перед каждым запуском.

Не ставьте в эту папку вручную другую версию того же мода: packwiz управляет только перечисленными файлами и не обязан удалять посторонние JAR. Если возникнет дубликат модов, сверяйте папку `mods` с манифестом, не удаляя файлы наугад. В существующем инстансе packwiz не тронет личные сохранения/настройки, но может заменить или убрать **отслеживаемые** им версии модов и ресурспаков — поэтому нужна копия.

## Как добавлять моды дальше

Меняйте манифест в `packwiz/`, затем выполняйте там `packwiz refresh` и публикуйте изменения в ветку `main` этого репозитория. Для CurseForge/Modrinth используйте `packwiz curseforge add` / `packwiz modrinth add`; для своего JAR нужен стабильный прямой HTTPS URL и хеш в `*.pw.toml`. Проверяйте совместимость с Minecraft 1.21.1, NeoForge 21.1.249 и сервером; серверные моды packwiz-клиент сам на сервер не установит.

Не запускайте `packwiz update --all`: это обновит моды отдельно от Craftoria. Для новой версии каждого мода сначала проверьте совместимость и согласуйте обновление сборки/сервера.

Для локальной проверки перед публикацией: из папки `packwiz/` выполните `packwiz refresh`, затем `packwiz list`. Изменённые `pack.toml`, `index.toml` и `*.pw.toml` нужно публиковать вместе: установщик сверяет их хеши.
